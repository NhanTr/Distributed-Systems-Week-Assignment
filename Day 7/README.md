# Day 7 Lab: Client-Centric Consistency Session Proxy Simulator

Python solution to the assignment on PDF pages 42-43 (slides 37-38). A proxy sits between clients and three replicated stores, tracks session vectors, and repairs stale replicas before serving reads.

## Run

Requires Python 3.9 or newer; uses only the standard library. Run from `Day 7`:

```bash
python3 -m unittest -v
python3 run_demo.py --output execution_trace.log
```

The demo prints and saves four assertion-checked scenarios: the lecture's Alice profile example, Monotonic Reads for a separate observer, delayed background propagation, and blocked-read recovery. Avoid `python -O` when running the demo because it disables its assertions.

## Use the proxy

```python
from session_proxy import Cluster, SessionProxy

cluster = Cluster(replication_delay=5, emit=print)
proxy = SessionProxy(cluster)
proxy.write('alice', 'S1', 'profile', 'Alice')

# S2 is stale until the proxy fetches W1 from S1.
assert cluster.raw_read('S2', 'profile') is None
assert proxy.read('alice', 'S2', 'profile') == 'Alice'

# A logical tick advances background message delivery, without real sleeping.
cluster.advance(5)
assert cluster.raw_read('S3', 'profile') == 'Alice'
```

`raw_read` intentionally bypasses session guarantees for demonstrating an anomaly. Application operations should use `SessionProxy`. A session ID identifies one client history. Reads return a string or `None` for a missing key; writes accept string values, including the empty string.

`set_online('S1', False)` simulates an unreachable node while preserving its memory. The proxy raises `UnavailableError` if it cannot obtain required history; retry after restoring reachability. Offline recipients retain delayed deliveries in the simulated network queue.

This is a deterministic, single-threaded simulator, as requested by the lab. Replicas are independent store objects rather than network servers. Logical ticks model background delay, while on-demand fetching is synchronous and logged. There are no sockets, persistent recovery logs, actual wall-clock delays, or guarantees across program restarts.
